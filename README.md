# Frontend - Lago Azul (Vue 3 + Vite)

Interfaz de usuario para el sistema de inventario Lago Azul.

## Tecnologías
- Vue 3 (Composition API)
- Vite
- Vue Router

## Instalación Local
1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Crear un archivo `.env` basado en el `.env.example`.
4. Ejecutar `npm run dev`.

## Despliegue en Vercel
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Variables de entorno necesarias:** `VITE_API_URL` (URL del backend en Render, ej. `https://backend.onrender.com/api`).
